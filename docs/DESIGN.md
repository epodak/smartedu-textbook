## 一、三个数据源的实测对比（本设计的基石）

调研中发现平台有三处可拿教材信息，**质量差别很大，选错就下到旧版教材**：

| 数据源 | 地址 | 实测结论 |
|---|---|---|
| ❌ 老目录接口 | `.../zxx/ndrs/tch_material/version/data_version.json` | **403**。网上大量教程基于它，已失效（路径少了 `resources/`） |
| ⚠️ 单本详情接口 | `.../resources/tch_material/details/{id}.json` | 200 可用，但**数据过期**：给的是 2023 年的旧版资源，且 `provider_list` 返回的是平台方而非出版社 |
| ✅ **目录分片** | `.../resources/tch_material/version/data_version.json` → 4 个 `part_*.json` | **权威且最新**。3637 本教材全量元数据，含正确的图片坐标和真实出版社 |

**结论：一律以目录分片为准，不要用 details 接口。**

### 1.1 目录分片的取法

```
GET .../zxx/ndrs/resources/tch_material/version/data_version.json
→ { "module_version": 1919079415,
    "urls": "https://…/part_100.json,https://…/part_101.json,…" }   ← 逗号分隔的 4 个分片
```

4 个分片合计约 **33 MB / 3637 本**（小学 1282、初中 871、高中 516）。
`module_version` 用于判断缓存是否过期。

### 1.2 单本条目里可用的字段

| 字段 | 值示例 | 用途 |
|---|---|---|
| `id` | `c0cc18a9-…` | contentId |
| `title` | 义务教育教科书·数学三年级上册 | 文件名 |
| `tag_list[].tag_name` | 三年级 / 数学 / **苏教版** / 上册 / 小学 | **建文件夹 + 搜索** |
| `provider_list[0].name` | **江苏凤凰教育出版社** | **建文件夹**（详情接口拿不到这个） |
| `custom_properties.preview` | 各页图片 URL | **提取 contentId + timestamp** |

图片坐标从 preview 里任取一条解析：

```
https://r3-ndr…/assets/{contentId}.t/zh-CN/{timestamp}/transcode/image/{n}.jpg
```

**坐标可用率实测 84.8%（3085/3637）**，其余 15.2% 无 preview，走回退方案（见 2.2）。

## 二、⚠️ 核心陷阱：版本错配

同一本三年级数学，两个来源给出不同 timestamp，**指向不同版本**：

| timestamp 来源 | 第 1 页 | 第 50 页 | 第 132 页 |
|---|---|---|---|
| details 接口 `1688374778076`（≈2023-07） | ✅ | ✅ | **❌ 403** |
| 目录分片 `1754968748479`（≈2025-08） | ✅ | ✅ | **✅** |

2024–2025 正是义务教育教材按 2022 版新课标换版的窗口，**下错版本 = 拿到旧教材，单元结构全对不上**。

阴险之处在于**它不报错**：文件能下、PDF 能合成、页数看着也正常，
只有翻到版权页或最后几页才发现不对。

**三重防护（必须实现）**：
1. 坐标只从**目录分片**取，代码里不给 details 接口留调用入口
2. 下载完成后在结果里打印 `title` + `timestamp` + 总页数，并提示"请翻到版权页核对版次"
3. `info.json` 存档完整坐标，日后可追溯"我下的到底是哪一版"

## 三、用户交互

### 3.1 主路径：说出教材，直接下（覆盖 84.8%）

用户不需要打开浏览器、不需要复制任何 URL。

```bash
python scripts/download.py --search "苏教版 三年级 数学 上册"
python scripts/download.py --grade 三年级 --subject 数学 --version 苏教版 --volume 上册
```

匹配逻辑：对 `title` 和 `tag_list` 做分词匹配 →
- 唯一命中 → 直接下载
- 多个命中 → 列出编号让用户选（**不猜**）
- 零命中 → 打印该条件下的可用维度值（例如"三年级+数学 有这些版本：人教版/苏教版/北师大版…"）

辅助命令：
```bash
--list --grade 三年级 --subject 数学      # 看有哪些版本可选
--refresh                                  # 强制刷新目录缓存
```

### 3.2 回退：直接给坐标（覆盖剩余 15.2% 及目录失效时）

```bash
--url "<在平台上右键封面图复制的图片地址>"
--id <contentId> --ts <timestamp>
```

**为什么保留回退**：平台接口随时可能变，而封面图 URL 是页面上肉眼可见的稳定信息。
目录一旦挂掉，工具不至于完全不可用。

### 3.3 批量

```bash
--batch books.txt      # 一行一个搜索词或 URL
```

## 四、输出目录（决策 A3 定稿）

```
~/Desktop/教材下载/
  三年级上册/                                   ← 年级 + 册次
    数学/                                       ← 科目
      苏教版（江苏凤凰教育出版社）/               ← 版本（出版社全名）
        义务教育教科书·数学三年级上册.pdf
        info.json
```

三层全部从目录元数据自动生成，**无需任何内置映射表**。
文件名非法字符（`\ / : * ? " < > |`）统一替换为全角或下划线。

`info.json` 内容：contentId、timestamp、页数、下载时间、来源、title、tags、出版社。

**单页图片不保留**（决策 B）：合成 PDF 后删除临时目录。
提供 `--keep-pages` 供需要单页时使用。

### 4.1 桌面路径的跨平台处理

| 系统 | 取法 | 坑 |
|---|---|---|
| Windows | 读注册表 `HKCU\…\Shell Folders\Desktop` | **OneDrive 会重定向桌面**，直接拼 `%USERPROFILE%\Desktop` 会建错地方 |
| macOS | `~/Desktop` | — |
| Linux | `xdg-user-dir DESKTOP`，回退 `~/Desktop` | 非中文环境目录名可能不同 |

`--out <dir>` 可覆盖默认路径。

## 五、健壮性（发布级要求）

| 项 | 做法 |
|---|---|
| **页数探测** | 倍增找上界 → 二分定位末页，约 12–16 次请求（不是逐页试） |
| **403 歧义** | 403 既可能"到头"也可能限流 → 隔 1.5s 二次确认才判定 |
| **并发** | 默认 8，`--jobs` 可调，**硬上限 16**，不提供无限并发 |
| **重试** | 每页最多 3 次，指数退避 1/2/4s，三镜像 r1→r2→r3 轮换 |
| **断点续传** | 已存在且 >2KB 的页跳过，中断后重跑即可 |
| **完整性** | 校验 JPEG 尾字节 `FFD9`，不合格重下；结束打印失败页清单，**绝不静默丢页** |
| **PDF 合成** | 优先 `img2pdf`（无损、内存低）；回退 Pillow 惰性打开，**禁止 `convert()`**（132 页会吃满内存，已踩过） |
| **目录缓存** | 存 `~/.cache/smartedu/`，按 `module_version` 判断过期 |
| **依赖检查** | 启动检查 requests/Pillow，缺失给出明确安装命令而非堆栈 |
| **礼貌抓取** | 自定义 UA、请求间隔、`--slow` 弱网模式 |

## 七、合规与免责

1. 平台由**教育部主办**，电子教材本就免费向师生公开；本工具**不破解、不绕过任何鉴权**，
   **明确不实现**需要登录的 PDF 通道
2. 教材版权归各出版社所有，**仅供个人教学/学习使用**
3. **禁止**商业用途、**禁止**二次分发教材文件、**禁止**规模化爬取
4. 内置速率限制与并发上限，不提供解除开关
5. 平台接口随时可能变更或关闭，不保证长期可用

以上同时写入 README.md 与 SKILL.md。

## 九、已知限制（写入 README）

- 约 **15.2%** 的教材（552/3637）目录里无 preview 坐标，需走 `--url` 回退
- 高中教材部分为分册/选修，命名不如义务教育规整，搜索可能需要人工确认
- 平台偶发限流，弱网建议 `--jobs 4 --slow`
- **不下载**教师用书、课件、音视频——本工具只做电子课本
